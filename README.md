# Bot-resenha-BY-GUH
bot discord feito em python com IA integrada sem filtro e sem censura 

Bot utiliza a API Openrouter para os comandos /chat e /investigar
utiliza a API openweathermap para o comando /clima que verifica clima de todos os estados e cidades do Brasil

 comandos de brincadeiras como quiz, adivinhar, desenhos, e entre outras diversoes
 futuramente será adicionado a funcao para jogo da velha e outras brincadeiras materias

as materias, conteudos e perguntas dos quiz estao nos arquivos json na pasta
 bot altamente automatizado e versatil para resenha com amigos
